NetPulse: Real-Time Network Traffic Analysis System

Project Abstract: Modern computer networks generate a continuous and increasing volume of traffic, making it difficult for administrators to monitor communication, identify abnormal activities, and respond to network issues in real time. This project implements a Real-Time Network Traffic Analysis System that captures, analyzes, and visualizes traffic as it occurs, showing source/destination addresses, protocols, packet counts, bandwidth utilization, and traffic patterns, and highlighting significant deviations from established baselines.

Core System Objectives

Architectural pillars of the NetPulse traffic analysis engine
01

Layer 2-7 Deep Packet Dissection

Captures raw frames from network adapters via Scapy or realistic synthetic stream, decomposing Ethernet, ARP, IPv4/IPv6, TCP flags (SYN/ACK/FIN/RST), UDP datagrams, ICMP echo, and DNS queries with header inspection.

02

Non-Blocking Real-Time Streaming

Dual-threaded pipeline isolating capture from presentation. In-memory circular deques (O(1)) push 1 Hz JSON telemetry frames over WebSockets for live 60-second bandwidth timelines and protocol distribution charts.

03

Heuristic & Statistical Anomaly Engine

Computes rolling mean and standard deviation to detect deviations with Z-score > 3.0. Integrates rule-based IDS heuristics for port scanning, TCP SYN floods, ICMP echo floods, and DNS query spikes with SQLite persistence.

04

Ethical Network Audit Module

Integrated multithreaded TCP/UDP port scanner inspired by the open-source SharkTooth tool with strict RFC1918 private/loopback safety bounds, latency metrics, and Prometheus monitoring.

OSI & TCP/IP Protocol Stack Dissection Model

How NetPulse decomposes incoming frames across the standard 5-layer internet protocol stack:

Layer 2 // Data Link
Header Fields: Source MAC, Destination MAC, EtherType (0x0800 IPv4, 0x0806 ARP, 0x86DD IPv6).
NetPulse Dissection: Physical NIC frame framing and ARP cache resolution mappings.
Layer 3 // Network
Header Fields: Source IP, Destination IP, TTL, IHL, Total Length, Protocol ID (6 TCP, 17 UDP, 1 ICMP).
NetPulse Dissection: Host tracking, geolocation mapping, IP-level volume aggregation, ICMP echo floods.
Layer 4 // Transport
Header Fields: Source Port, Destination Port, Seq/Ack numbers, TCP Flags (SYN, ACK, RST, FIN, PSH, URG), Window size.
NetPulse Dissection: Service recognition, 3-way handshake analysis, SYN flood detection, port scan heuristics.
Layer 7 // Application
Header Fields: DNS Query/Answer records, HTTP Methods/Status, TLS handshake SNI.
NetPulse Dissection: Protocol classification (DNS, HTTP, HTTPS), tunneling anomaly detection, payload inspection.

⚙ Architecture & Engineering Pipeline

System design, threading isolation, viva knowledge digest, and project credits
View Mode:
01 // Multi-Vector Traffic Ingestion Layer
Raw Ingestion
Live Adapter Sniffer Npcap / libpcap
Executes promiscuous mode raw packet capture using Scapy at Layer 2. Leverages kernel-level Berkeley Packet Filters (BPF) to drop unneeded frames before user-space memory copying.
Synthetic Attack Generator Demo Mode
High-fidelity simulated multi-protocol generator (HTTPS, DNS, SSH, ARP, ICMP). Supports live attack injection (Port Scans, SYN floods, ICMP storms, DNS tunneling) for academic demonstration.
▼ Non-Blocking Raw Frame Stream (Thread-Safe Handoff) ▼
02 // Packet Dissection & Bounded Ring Buffers
L2-L7 Parsing
Deep Protocol Dissector Scapy Decapsulator
Decapsulates headers layer-by-layer: Ethernet MACs, ARP caches, IPv4/IPv6 TTL, TCP 6-flag bitmask (SYN/ACK/FIN/RST), UDP length, ICMP types, DNS QNAMEs, and extracts raw payload hex/ASCII.
In-Memory Ring Buffers O(1) collections.deque
Maintains thread-safe circular deques protected by recursive locks (threading.RLock). Old frames are purged automatically in constant $O(1)$ time, eliminating memory leaks.
▼ Decoupled Analytical Feeds to Dual Intelligence Engines ▼
03 // Dual Intelligence & Analytics Processing
1 Hz Sampling
TrafficAnalyzer (Telemetry) Metrics Aggregator
Compiles 60-second sliding bandwidth history (KB/s & PPS), aggregates L2-L7 protocol distributions, ranks Top 10 talkers by volume, and tracks active bidirectional 5-tuple socket connections.
AnomalyEngine (Hybrid IDS) Z-Score & Heuristics
Calculates rolling Gaussian mean ($\mu$) and standard deviation ($\sigma$). Flags statistical anomalies ($|Z| > 3.0$). Evaluates deterministic signatures for port scans, SYN floods, and ICMP floods.
▼ Multi-Channel Broadcast & Metric Persistence ▼
04 // Persistence, Metrics & Telemetry Broadcast
Distribution
SQLite Incident Database alerts.db
Persists structured security events with timestamp, severity, source IP, target IP, and anomaly scores. Exposes downloadable CSV audit report for incident forensics.

Native WebSocket Server /ws/traffic
FastAPI asynchronous full-duplex WebSocket broadcasting a unified 1 Hz JSON telemetry snapshot directly to all connected browser sessions without HTTP polling overhead.

⚡
Thread Isolation & Zero Packet Drops
The Scapy packet capture worker executes in an isolated background thread completely decoupled from the asynchronous WebSocket event loop. Heavy UI rendering or client reconnects cannot stall packet ingestion.
🔒
O(1) Bounded Memory Architecture
All sliding windows use Python's collections.deque(maxlen=N). Appending new packets discards the oldest item in constant $O(1)$ time, guaranteeing zero memory bloat during 24/7 continuous operations.
🛡
Hybrid Anomaly Detection Model
Blends statistical standard score modeling ($Z = \frac{X - \mu}{\sigma} > 3.0$) with deterministic rule-based signatures for SYN floods, port scans, and ICMP floods to achieve high precision with near-zero false alarms.
